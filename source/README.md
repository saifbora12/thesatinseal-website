# The Satin Seal website

React + Tailwind CSS v4 + Vite.

    npm install
    npm run dev      # local preview
    npm run build    # production files in dist/ – upload to Netlify, Vercel or any host

Edit: `src/App.jsx` (top: ORDER_URL, TURNAROUND, PLANS, ADDONS, FAQS), `src/themes.js` (designs), `src/styles.css` (brand colours/fonts).
